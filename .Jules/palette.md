## 2026-04-18 - Interactive Dashboard Controls & Render Phase Derivation
**Learning:** In live simulation widgets (like high-frequency charts and SVG canvases), icon-only interactive controls (play/pause, reset) and range inputs are easily overlooked in assistive tree hierarchies. Adding `aria-label`, `title`, and associated `<label>` attributes paired with `focus-visible:ring-2` ensures keyboard users and screen readers can comfortably navigate real-time dashboards without relying purely on visual cues. Additionally, in React 19, computing simulation-derived metrics (such as PnL) directly during render rather than calling synchronous `setState` in `useEffect` prevents cascading render lint errors while keeping display metrics in lockstep with incoming data ticks.
**Action:** Always provide explicit accessible names (`aria-label`, `title`) and keyboard focus rings for icon-only dashboard control buttons and slider inputs, while deriving state directly during the render cycle.
