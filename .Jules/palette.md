## 2026-03-30 - Interactive Live Chart Control Accessibility
**Learning:** Icon-only playback controls and SVG chart visualizations in dark-themed financial UI need explicit `aria-label`s, `role="img"`, `<label>` pairings for slider controls, and `focus-visible:ring-2` focus outlines to ensure full screen reader and keyboard accessibility.
**Action:** Always provide explicit ARIA labels and focus visibility rings when building custom icon controls and SVG visualizations in interactive dashboards.
